# 更新说明 · v1.2.0

> 从 1.1.0 升级到 1.2.0，只新增功能与展示层改动，原有指令、权限、播报逻辑、异常兜底均不变。

## 一、新增：网页会话可辨认

网页面板开的会话以前在数据面板里只有一串 `webchat:FriendMessage:webchat!...`，分不清是哪一次对话。现在：

### 1. 自定义标题（手动）

在网页聊天框里直接发：

```
#标题 复习计划
```

- 面板里该会话显示为 `网页面板【复习计划】a6e87eeb`
- 标题持久保存在 `session_meta.json`
- 想改就再发一次 `#标题 新名字`；发 `#标题`（不带内容）清除标题
- 清除标题后自动回到 AI 摘要
- 清空上下文 / 清理闲置会话时，标题一并清除

> `#标题` 只对网页会话生效，QQ 私聊里发它不会拦截消息。指令本身不经过模型，回复一句确认就结束。

### 2. AI 摘要（自动）

没有设备注的网页会话，面板会显示：

```
网页面板｜摘要：哪吒2票房数据查询｜e467590a
```

- 摘要由当前会话使用的模型生成，读该会话最近 14 条消息，输出不超过 20 字的一句话
- 只在点【重新读取】时生成，结果缓存；会话有新消息才重新生成
- 生成失败显示「摘要获取失败」，同一会话 10 分钟内不重复尝试
- 没有任何对话内容时显示「尚无对话」
- 12 秒超时保护，失败不影响其它会话加载

### 3. 分组

数据面板从「私聊 / 群聊」两组，改为「网页面板 / 私聊 / 群聊」三组：

- 网页面板会话单独成组，不再混进 QQ 私聊
- QQ 私聊仍按管理员隔离；网页会话属于后台视角，管理员全量可见

## 二、新增：清理闲置网页会话

- 数据面板列表右上角新增【清理闲置网页会话】按钮
- 判定标准：网页会话超过 7 天没有新消息
- 按钮左侧会提示「闲置 N 个」，没有闲置时不显示数字
- 点击后二次确认，确认后逐条备份 → 删除会话 → 清除其备注/摘要缓存
- 返回删除数量，面板自动刷新

## 三、行为细节

| 场景 | 表现 |
| --- | --- |
| 发 `#标题 xxx` 但当前还没有会话 | 自动新建一个网页会话并命名，不用先聊一句 |
| 发 `#标题` | 清除标题，回到摘要显示 |
| 摘要生成中 | 显示「摘要获取中…」（首次刷新时短暂出现） |
| 模型不可用 / 超时 | 显示「摘要获取失败」，只写调试日志 |
| 面板刷新 | 摘要走缓存，不重复调模型 |

## 四、配置与文件

- 新增 `data/plugin_data/astrbot_plugin_token_panel/session_meta.json`：会话备注 + 摘要缓存
- `settings.json` 结构不变（v1.1.0 的设置可直接沿用）
- 清空上下文前仍会备份到 `cleared/`

## 五、兼容性

- `/token_ctx`、`/token_ctxon`、`/token_ctxoff`、`/token_clearctx`、`/token_ctxset` 全部保持不变
- 不占用原生 `/ctx`、`/clearctx`
- 与 LivingMemory、表情包、self-learning、self-evolution、说说等插件无交互
- 适配 SnowLuma：网页会话识别只看 `platform_id` 是否以 `webchat` 开头
- 依旧完全本地运行，不联网

## 六、升级方式

1. 覆盖 `main.py` 与 `views/dashboard/index.html`
2. 后台「插件」页重载 `astrbot_plugin_token_panel`（或重启 AstrBot）
3. 打开面板确认页脚显示 `v1.2.0`
