# PLUTO panel v1.3.0 更新说明

> 版本 1.3.0 · 2026-10-29
> 主题：把「上下文统计」和「上下文压缩和承接」两个插件正式并入 PLUTO panel，面板里直接能看、能压、能承接。

---

## 一、这次做了什么

| 项目 | 说明 |
| --- | --- |
| 整合 `ctx_stats` | 原生 `/ctx` 指令、统计卡片、窗口上限解析逻辑整段搬入，口径与原版一致 |
| 整合 `ctx_carry` | 压缩/承接算法、`SUMMARY_PROMPT` 摘要模板、提示文案、备份策略逐字保留 |
| 新增指令 6 条 | `ctx` `ctx_compress` `ctx_continue` `ctx_sessions` `ctx_switch` `ctx_auto` |
| 新增面板标签「压缩承接」 | 窗口/自动压缩/保留轮数/摘要字数可调，下方带压缩日志 |
| 数据面板每行加按钮 | 查看统计、压缩上下文、生成承接摘要、清空上下文 |
| 自动禁用旧插件 | 启动时禁用「上下文统计」「上下文压缩和承接」同名插件，只禁用不删文件 |
| 版本号 | `metadata.yaml` 与页脚统一为 1.3.0 |

原有 v1.2.0 的功能（网页会话 `#标题` 备注、AI 摘要、闲置清理、双主题双画布、预警播报）**全部保留**。

---

## 二、新增面板

数据面板每行会话右侧四个按钮：

1. **查看统计** —— 弹窗显示模型 / 已用 / 窗口上限 / 剩余 / 占用 / 轮数，附带状态提示；
2. **压缩上下文** —— 二次确认后压缩该会话（摘要 + 保留最近 N 轮），旧历史先备份；
3. **生成承接摘要** —— 二次确认后新建带摘要的会话并切换过去；
4. **清空上下文** —— 原有能力，同样先备份。

面板右上角多出「闲置」计数与「清理闲置网页会话」按钮（默认 7 天）。

「压缩承接」标签：

- 估算窗口（默认 128000）
- 请求内自动压缩开关 + 触发线（默认 80%）
- 默认保留轮数（默认 8）
- 摘要字数上限（默认 500）
- 压缩日志：时间 / 类型 / 会话 / 压缩前 token → 压缩后 token / 保留轮数，最多 200 条

## 三、指令变化

新增：

```
/ctx                              所有人   上下文统计
/ctx_compress                     管理员   压缩当前会话
/ctx_continue                     管理员   承接并切换新会话
/ctx_sessions                     所有人   列出会话分支
/ctx_switch <ID前缀>              管理员   切换到指定分支
/ctx_auto on|off [0.0~1.0]        管理员   自动压缩开关与触发线
```

不变：

```
/token_ctx  /token_ctxon  /token_ctxoff  /token_ctxset  /token_clearctx
```

> 旧插件里的中文指令 `/压缩` `/承接` `/切换` `/自动压缩` 不再注册（避免与现有指令表冲突），统一改用上面 6 条。

## 四、数据与文件

新增落盘文件（都在 `data/plugin_data/astrbot_plugin_token_panel/`）：

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 原有面板设置 + `carry` 段 |
| `session_meta.json` | 网页会话的标题/摘要缓存（1.2.0 已有） |
| `compress_log.json` | 压缩日志（只记录，最多 200 条） |
| `carry_backups/` | 压缩/承接前的会话历史备份 |

---

## 五、兼容与容错

- 自动禁用旧插件时只调用 `turn_off_plugin`，**不删除任何文件**，行为可逆；
- 禁用动作放在后台任务里执行，避免插件加载时与插件管理器互锁；
- 所有读库、读 Provider 上限、调模型的地方都有 try/except 与超时，失败只降级为提示文案；
- 不新增任何联网请求；
- 面板、指令、播报互不影响，未使用 `/ctx*` 时与旧版行为完全一致。

---

## 六、升级方式

1. 覆盖 `data/plugins/astrbot_plugin_token_panel/`（或重新跑安装脚本）；
2. 后台「插件」页点重载；
3. 首次加载后看日志是否出现：

```
[token_panel] 已自动禁用旧插件：astrbot_plugin_ctx_stats, astrbot_plugin_ctx_carry
```

4. 打开「扩展功能 → PLUTO panel → 压缩承接」，确认四项配置已读到底值（128000 / 关 / 80% / 8）。

> 想回退：把旧版 `astrbot_plugin_ctx_stats`、`astrbot_plugin_ctx_carry` 目录手动启用，再停用本插件的 `ctx*` 指令即可（插件本身不删文件）。
