## 一、这次修的是什么

后台「插件详情 → 文档栏」里，README 的「界面预览」6 张截图全部裂图，只显示 alt 文字。

**根因（代码层面）**

1. `astrbot/dashboard/services/plugin_service.py:1943 get_plugin_readme()` 只把 `README.md` 读成字符串交给前端，**不重写图片路径**。
2. `astrbot/dashboard/api/static_files.py` 的静态路由只服务后台自身 SPA 资源，**没有把插件目录挂成静态目录**。

于是浏览器把 `assets/screenshots/context-dark.jpg` 解析成 `http://127.0.0.1:6185/assets/screenshots/context-dark.jpg`，该路径下没有任何资源，必然 404。

这不是插件能绕过去的：改成绝对 URL 会让 GitHub 那边裂图，改成 HTML 标签也一样解析不了相对路径。
