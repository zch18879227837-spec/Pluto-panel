# PLUTO panel v1.11.0 更新说明

> 新增「大肥鱼小屋」：面板里多了一间等距像素小屋，角色是你上传的那张图，能点着地走，也能用 QQ 指令喊她过去。

## 一、这一版新增了什么

| 能力 | 说明 |
| --- | --- |
| 等距房间 | 12×9 菱形网格，夜间海景背景，右侧墙面是带月亮与海浪的窗 |
| 默认家具 | 床、衣柜、书桌电脑、展示架、沙发、茶几、地毯、绿植 |
| 点击寻路 | 点地面任意可走格，角色用 A\* 寻路平滑走过去（GSAP 补间） |
| 自动走动 | 右上开关，开启后在漫游区域里自主溜达；停留时长、区域范围可调 |
| 角色素材 | 只认管理员上传的参考图，面板里可随时替换；不做自动绘制 |
| 布局编辑 | 家具与点位增删改名改坐标，保存后立即生效 |
| 行为日志 | 右侧实时记录移动、指令、设置，跟随深浅主题 |
| QQ 指令 | `/去 点位名`、`/自动走动`、`/开启自动走动`、`/关闭自动走动`、`/停下`、`/小屋` |
| LLM 工具 | `house_control`：模型可以让她去某处、开关自动走动、读当前状态 |

## 二、怎么用

1. 面板左侧导航点「大肥鱼小屋」。
2. 第一次进来先点「上传参考图」，选你画的那张大肥鱼；角色会用这张图作为唯一形象依据。
3. 直接用鼠标点房间地面，她会走过去；想让她自己溜达就打开右上「自动走动」。
4. 想加家具或改点位，在下面「房间布局」里改，点右上「保存布局」。
5. 在 QQ 里发 `/去 懒人角落`（点位名随便起），面板开着的话 6 秒内就能看到她动身。

## 三、状态存在哪

- 全部落在 `settings.json` 的 `isohouse` 段：网格、家具、点位、当前位置、漫游参数、行为日志、偏好点位。
- 角色素材存在 `plugin_data/isohouse/`，只保留当前使用的一张，替换即覆盖引用。
- 不新建数据库，不新建记忆库；记忆联动复用原来的日记本与管理员鉴权。

## 四、已知限制

- 角色是整张贴图，没有拆方向帧；走路用左右轻摆 + 上下浮动模拟步态。
- 家具遮挡角色还没做图层排序，角色目前始终画在最上层。
- 房间画布按卡片宽度自适应，窗口很窄时角色会比较小。

## 五、升级方式

把插件目录替换为 v1.11.0 后重载插件即可，旧数据（会话、置顶、事件日志、抖音配置）不受影响。
