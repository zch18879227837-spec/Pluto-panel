# PLUTO panel v1.12.0 更新说明

> 小屋从「能走动的贴图」变成一间真的夜间海景房：整面落地窗、月光铺地、参数全放开，还能在面板里直接跟她说话。

## 一、画面

| 项 | 说明 |
| --- | --- |
| 场景 | 低饱和深蓝夜景，12×9 等距房间，右侧整面海景落地窗 |
| 窗外 | 月亮与光晕、海面波光与倒影、远处棕榈剪影 |
| 光 | 月光从窗口斜射，在地板形成光池；桌面屏幕有冷色自发光 |
| 地面 | 细腻暗网格（透明度可调），四周暗角收拢视线 |
| 画布 | 679×468（随窗口自适应），行为日志移到画布下方，画布成为主视觉 |

## 二、角色

- 素材仍然只认管理员上传的参考图，不自动生成。
- 脚底接触阴影按光源方向偏移，不再是「贴地悬浮」。
- 环境融合：压饱和 + 轻微提冷 + 月光冷边，强度 0–1 可调；调到 0 就是原始贴图。
- 角色缩放、阴影浓度、气泡高度偏移都在「外观 · 光源 · 气泡」里。

## 三、参数（全部持久保存，支持一键恢复默认）

| 分组 | 参数 |
| --- | --- |
| 角色 | 缩放、脚底阴影、环境融合、气泡偏移 |
| 漫游 | 范围、停留时长、移动速度、随机权重、优先访问交互点位 |
| 点位 | 名称、坐标、备注、是否可交互、预设台词（每行一句） |
| 家具 | 坐标、宽高、是否阻挡寻路、是否可交互 |
| 渲染 | 网格线透明度、点位颜色、交互点位色、光源方向、月光强度 |
| 气泡 | 停留时长、底色、字色、最大宽度、不透明度 |

保存位置：`settings.json` 的 `isohouse` 段。新增字段会自动补全，旧配置无需迁移。

## 四、对话

1. 面板底部输入框 →「对话」：走当前模型，带上日记本里检索到的记忆和小屋当前位置，回复以气泡显示在头顶，并写进行为日志。
2. 「只显示气泡」：不经过模型，直接把你这句话当她说的显示出来（用来做画面/截图很方便）。
3. QQ 里正常聊天时，她的回复会同步成小屋气泡；`/说 文本` 可以直接让面板冒一句。
4. 气泡跟随角色移动，多条纵向错开，超时自动消失。

## 五、已知限制

- 家具与角色的前后遮挡仍是「角色永远在最上层」，没做逐层排序。
- 气泡是自适应宽度的纯文本，不含富文本与表情图。
- 面板对话走一次模型调用，会消耗 token。

## 六、升级方式

替换插件目录后重载插件即可；旧的会话、置顶、事件日志、抖音配置、小屋布局都保留，新增参数取默认值。
