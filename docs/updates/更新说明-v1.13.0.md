# PLUTO panel v1.13.0 更新说明

**日期**：2026-10-31　**类型**：功能增强（小屋模块）

这次只动「大肥鱼小屋」，其他模块（双主题、上下文置顶、事件日志、联网搜索、主动消息、抖音浏览、手机操控）一行未改。

## 一、角色终于「有动作」

以前角色就是一个贴图在地上平移，坐下、伏案都只是把图压扁。现在有一套状态机：

| 状态 | 触发 | 表现 |
| --- | --- | --- |
| `idle` | 默认 | 呼吸起伏，脚底阴影轻微缩放 |
| `walk` | 寻路中 | 沿路径逐帧推进，上下浮动 + 轻微左右摆 |
| `sit` | 床边 | 压扁加宽，坐下时先回 idle 再落座 |
| `sofa` | 沙发 | 同上，靠背方向偏移 |
| `desk` | 书桌 | 前倾 5.5°，像在敲键盘 |
| `gaze` | 窗边 | 视线轻微左右移动，看海 |

规则是硬的：**同一时间只有一个状态**；坐姿之间不能直接切；坐姿要移动必须先起身回 `idle`，再寻路。所以不会再出现「坐着滑到沙发上」这种画面。

## 二、站位与遮挡

- 你点的格子如果压在家具上，后端 `legal_spot()` 会向外找最近的可站格，角色停在床前/沙发前/书桌前才播动作。
- 家具按深度拆前后两层画，角色走到沙发后面会被挡住一角，走过去又露出来。

## 三、像素化精灵

上传的原图不会被重画，只做画风适配：最近邻降采样成像素格，再配一层环境冷调，脚底是跟着窗户光往左偏的像素软阴影。`像素化强度` 从 0.15（接近原图）到 1（很粗的像素块），默认 0.55。

## 四、场景独白

走到可交互点位（床边、窗边、懒人角落…）停稳后，会按「点位台词 → 点位备注 → 全局记忆」取素材，说一句当下的独白，比如窗边：

> 窗台的木头有点凉。海面碎碎地闪，像有人把银纸揉开了。

同一场景 240 秒内不重复；点位台词可以在面板里逐条编辑。

## 五、新配置在哪

面板 → 大肥鱼小屋 → 「外观 · 光源 · 气泡」卡片：

- 像素化强度 `iso-pixel`（0.15–1）
- 角色缩放、阴影透明度、气泡偏移
- 点位行新增「姿态」下拉：自动 / 站 / 坐床 / 坐沙发 / 伏案 / 发呆

## 六、已知限制

1. 目标格被挡时只做一次外扩搜索，不会绕到家具背后。
2. 气泡仍是纯文本。
3. 参数类指令下发即生效，没有二次确认。

## 七、兼容性

- 存储格式向后兼容：旧 `settings.json` 缺的新字段自动补默认值，`/小屋` 里可以一键恢复默认。
- 升级方式：覆盖插件目录后重载插件即可，无需迁移数据。
