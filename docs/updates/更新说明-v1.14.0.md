# PLUTO panel v1.14.0 更新说明

**日期**：2026-10-31　**类型**：视觉更新（大肥鱼小屋）

这次只改画面，小屋的功能、数据、配置和其他模块（双主题、置顶、事件日志、搜索、主动消息、抖音、手机操控）都没有动。

## 一、画面基准

按给的参考图重画：石板蓝夜色、菱形地砖、整面海景落地窗、扁平带白边的家具。整套配色仍是程序化生成，换主题时跟着面板令牌走。

| 元素 | 做法 |
| --- | --- |
| 地板 | 12×9 菱形方砖，砖缝浅色细线，房间外沿加厚底座 + 青色描边 |
| 墙 | 左墙暗面 + 踢脚线，右墙整面带窗棂的落地窗 |
| 窗外 | 深蓝夜空渐变、大月亮与光晕、星点、海面碎光、两棵棕榈剪影、海面倒影 |
| 光 | 月光斜切光柱落到地板形成光池，四周压暗角 |
| 家具 | 统一的等距盒子 + 顶面亮边，木色只给桌面和桌脚 |

## 二、家具清单

- **床**：木床架 + 白床垫 + 蓝色被子 + 枕头
- **衣柜**：石板灰双开门，带竖向门缝与两只拉手
- **书桌**：四条细木腿 + 立式显示器（青色冷光屏）+ 键盘
- **展示架**：三层隔板 + 三排彩色书脊
- **沙发**：座面 + 靠背 + 坐垫缝线
- **茶几**：薄台面 + 四条细腿 + 台面上的碗
- **绿植**：陶盆 + 五片叶子
- **地毯**：双层菱形，低透明度铺在地板上

## 三、修掉的两个小问题

1. 气泡在角色走开之后还停在原地 —— 现在每 0.2 秒跟着角色真实坐标重排，走到窗边气泡也在窗边。
2. 旧版那团暖色灯光叠在暗墙上会出现彩色边缘 —— 已移除，只保留显示器的青色冷光。

## 四、没有改变的部分

- 动作状态机、A* 寻路、合法站位、图层遮挡、场景独白、自动漫游全部保持 1.13.0 的行为。
- 所有配置项（像素化强度、角色缩放、阴影透明度、气泡偏移、点位姿态、家具布局）不变，旧 `settings.json` 直接可用。

## 五、已知限制

- 家具是代码拼的等距盒子，细节密度不如手绘像素图；想更精细可以继续在 `drawFurniture()` 里逐件加密。
- 角色仍只做整图像素化，没有分方向的多方向帧。
- 气泡仍是纯文本。
