# PLUTO panel v1.14.1 更新说明

**日期**：2026-10-31　**类型**：视觉修复（大肥鱼小屋）

1.14.0 把配色换成了参考图的石板蓝，但家具的拼装有几处错位，看着「不合理」。这一版只修家具和墙面，功能、数据、配置、其它模块全都没动。

## 一、修掉的六处问题

| 现象 | 原因 | 现在的样子 |
| --- | --- | --- |
| 沙发只有一块灰板 | 靠背/扶手用了投影后的像素坐标当格坐标，画到画布外 | 靠背 + 两块坐垫 + 两侧扶手 |
| 书架看不出是书架 | 柜身颜色和墙一样 | 独立深色柜体 + 三层粗层板 + 三色书脊 |
| 衣柜顶面像浮着的盖板 | 顶面比柜身亮太多、没有压边 | 加柜顶压边，柜门内嵌、拉手归位 |
| 显示器像立在地板上 | 底座高度从地面起算 | 改成从桌面起算，薄屏 + 青色屏面 |
| 家具像浮在半空 | 没有接触阴影 | 每件家具脚下一层柔和阴影 |
| 落地窗开在前墙 | 窗的锚点用了最外侧的墙 | 改到后墙 y=0，与左墙在远角相交 |

## 二、浅色主题的对比

浅色主题之前家具和墙面几乎同色，整屏发白。这一版把地板压到 `#E7ECF5 / #DDE4EF`、砖缝加深，家具用 `#C9D4E6 / #AAB8CD / #8D9CB4` 三档，描边 `rgba(40,60,90,0.16)`——家具的顶面、左面、右面能明显分开了。

## 三、没有改的部分

- A* 寻路、合法站位、动作状态机、图层遮挡、场景独白、自动漫游：一行没动。
- 所有配置项（像素化强度、角色缩放、阴影透明度、气泡偏移、点位姿态、家具布局）：不变，旧 `settings.json` 直接可用。
- 角色仍然是管理员上传的原图做像素化，没有多方向帧。

## 四、怎么升

覆盖插件目录后重载 AstrBot 插件即可；`settings.json` 不动。
