# PLUTO panel v1.14.2 更新说明

## 这次修什么

上一版把家具的「配色」对齐了参考图，但每件家具其实都少画了一侧面：等距投影下相机站在 `+x/+y` 方向俯视，真正朝向镜头的是 `x=x1` 和 `y=y1` 这两个立面，而代码一直在画被挡住的 `x=x0`。于是衣柜顶面像一块悬空的雨棚、书架的书浮在柜子上方、床和沙发看起来只有半边。

这一版把立面朝向修正了，并且把图层遮挡从「按角色深度切成前后两趟」改成画家算法。

## 修复清单

### 1. 家具立面朝向
- `boxOf()` / `slab()` 改为绘制 `q.b→q.c`（x=x1 面）与 `q.d→q.c`（y=y1 面），再补顶面。
- 效果：衣柜有正面双开门 + 可见侧面；书架的书坐在柜体里；床有床架、床头、被面与枕头四个层次；沙发能看出靠背-坐垫-扶手；书桌有桌面厚度与侧面；茶几是薄台面 + 四条腿。
- 深浅两套主题都跟着修正，浅色不再「糊成一片」，深色不再「一整块黑」。

### 2. 遮挡改为画家算法
- 绘制顺序：地毯（永远最底）→ 家具与角色按深度混排 → 逐个绘制。
- 角色深度 `st.charDepth + 0.0005`，家具 `itemDepth(f) + (x+y)*0.001`，同深度也有稳定先后。
- 效果：角色走到床后面会被床挡住上半身，走到沙发前面会挡住沙发；气泡锚点跟着角色真实坐标，不再压在头上。

### 3. 其它
- 家具接触阴影（浅色 0.10 / 深色 0.28）跟着新几何重新贴合地面。
- 窗户锚点保持后墙 `y=0`，与左墙在远角正确相交。

## 未改动

- A* 寻路、动作状态机（待机/行走/坐床/沙发/伏案/发呆/对话）、合法站位校验、场景独白、气泡系统、记忆联动、`settings.json` 的 `isohouse` 配置结构，全部没动。
- 只改了 `drawFurniture()` 里的拼装函数和 `draw()` 的绘制顺序。

## 升级方式

1. 覆盖 `astrbot_plugin_token_panel` 目录；
2. 面板「插件」页点一次「重载」，或重启 AstrBot；
3. 打开「大肥鱼小屋」页，深浅主题各看一眼即可。

配置与存档（`settings.json` 的 `isohouse` 段、`isohouse_log`）完全兼容，无需迁移。
