# PLUTO panel v1.15.0 更新说明

发布日期：2026-10-31 ｜ 类型：minor（新增开关 + 修复）

## 一、新增：观察窗（海景）开关

外观卡片顶部多了一个开关：

- **打开**（默认）：右墙整面海景——夜空、星点、月亮与海面碎光、棕榈剪影，月光斜柱照进地板。
- **关闭**：用帘子把窗遮上。18 道褶皱明暗交替，上有帘头、下有底边压条；深色主题是冷灰蓝布料，浅色主题是米白布料。同时窗棂、窗台高光、月光斜柱一起收起，房间只剩顶光。

关窗后，「光源方向」「月光强度」「背景」三项会**变灰并禁用**——窗外没光了，这三项没有意义；开关旁的提示文字会变成「已用帘子遮上，灯光设置已禁用」。

开关状态存在 `render.window_open`，点「保存外观」写入 `settings.json`，重载插件、切换主题都不会丢；点「恢复默认」会连窗一起恢复正常。

## 二、修复

| 问题 | 原因 | 现在 |
| --- | --- | --- |
| 家具脚下有纯黑大块、描边发粗、深色家具糊成一团 | 画家算法改造后 `drawFurniture` 少了 `only` 参数，整屋家具被重复画 9 遍，阴影与描边层层叠加 | 按 `only` 只画当前这一件 |
| 坐下时人悬空站着 | 姿态只改了缩放，没把位置挪到家具上 | `poseHost()` 吸附最近的床/沙发/书桌，锚点移到家具中心格、抬高到坐面高度 |
| 床边点位坐不上床 | (2,3) 到 2×2 的床距离 3 格，阈值 2.2 吸不住 | 阈值放宽到 3.0 |
| 茶几上的碗悬在桌外、还是蓝盘子 | 位置按桌高算错半格，配色沿用了强调色 | 落到桌面之上、缩小、换陶色 |
| 点位标记像地灯 | 大光斑 + 外圈光晕 | 小圆环 + 中心点，两种颜色区分可交互/普通 |
| 水面碎光像一排字幕 | 9 段横线挤在同一高度 | 散开、长短不一、透明度有别 |
| 角色偏大 | 贴图高度 1.42 格 | 收到 1.20 格，和家具比例更协调 |

## 三、兼容性

- 升级不需要迁移数据：新增的 `render.window_open` 缺省按 `true` 处理，旧配置打开就是开窗状态。
- 没有改动 A* 寻路、存储结构、记忆联动，也没有触碰抖音、搜索、事件日志等其他模块。

## 四、验证

- 面板加载无 console 报错；四个姿态 `沙发 → 沙发 / 床边 → 坐床 / 书桌 → 伏案 / 窗边 → 发呆` 均正确吸附并停稳。
- 开关切换实测：`aria-checked` true → false，三项设置同步加 `iso-off`，`render.window_open` 落库为 `false`，再点回 `true` 正常回写。
- 深浅两主题各截一张开窗、一张关窗对照图。
