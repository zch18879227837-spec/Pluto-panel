# PLUTO panel v1.15.1 更新说明

发布日期：2026-10-31 ｜ 类型：patch（新增总开关 + 两处修复）

## 一、新增：小屋功能总开关

卡片头部最左边多了一个「小屋功能」开关，默认打开。

关掉之后：

- 舞台盖一层半透明遮罩，提示「小屋功能已关闭 / 右上角打开「小屋功能」就能继续用」；
- 右侧行为日志、底部对话框变灰且不可操作，右上角「自动走动」同步变灰；
- 轮询与自动漫游一起停下——不会在后台继续走动、继续记日志；
- QQ 指令 `/去`、`/自动走动`、`/开启自动走动`、`/关闭自动走动`、`/停下`、`/说`、`/小屋`，以及 LLM 工具 `house_control`，统一回一句「小屋功能现在是关着的，去面板「大肥鱼小屋」把右上角的开关打开就行」；
- 对话不再向模型注入小屋上下文（`context_block()` 关闭时返回空）。

开关状态存在 `settings.json` 的 `isohouse.enabled`，重载插件保持不变；每次切换都会在行为日志里记一条「配置 · 小屋功能已开启 / 已关闭」。

## 二、修复

| 问题 | 原因 | 现在 |
| --- | --- | --- |
| 小屋开着，遮罩却一直显示 | `.iso-offline` 用了 `display:flex`，作者样式压过浏览器内置的 `[hidden]` | 补 `.iso-offline[hidden]{display:none}` |
| 卡片头部标题与标签折字 | 新增第二个开关后一行放不下 | 头部 `flex-wrap` + 标签 `white-space:nowrap` + 按钮收紧内边距，排成整齐一行/两行 |

## 三、兼容性

- 升级不需要迁移数据：`isohouse.enabled` 缺省按 `true` 处理，旧配置升级后就是开着。
- 没有改动 A* 寻路、存储结构、记忆联动，也不影响抖音、搜索、事件日志等其他模块。

## 四、验证

- 面板加载无 console 报错。
- 开关切换实测：`aria-checked` `true → false → true`，`iso-offs` 灰化类、遮罩显隐、`#iso-roam-switch` 透明度 `0.42` 均正确；`st.state.enabled` 同步落库。
- 关闭状态下重载插件，开关仍为关闭；四个坐姿吸附（沙发 / 坐床 / 伏案 / 发呆）不受影响。
