# PLUTO panel v1.16.0 更新说明

## 这一版改了什么

抖音模块整个换了一条路：不再用无头浏览器偷偷刷网页版，改成**直接操作你电脑上的抖音客户端**——
读窗口、截画面、用 Windows 自带的中文识别看图上的字，然后在窗口里滑一个视频就停。

### 新增
- **抖音 PC 客户端卡片**：面板「抖音浏览」页第一张卡，显示窗口在不在、有没有被最小化、有没有被挡住、
  是不是管理员权限运行；带「打开抖音 / 下一个 / 截一张」三个按钮，截图直接显示在下面。
- **`/抖音` 指令**：`状态` / `打开` / `下一个` / `截图` / `停止` / `确认`。除了看状态，都会先用平时的语气
  复述一遍要做什么，回「确认」才执行（120 秒内有效）。
- **模型工具 `douyin_pc`**：管理员用自然语言就能让它看一眼或滑一下，工具内部再验一次管理员身份。
- **截图识别**：Windows 自带 OCR（离线、免装模型）认出画面上的文字，据此判断当前是视频流、登录页还是安全验证。

### 变更
- **自动循环刷视频下线**：没有后台定时任务了，只有「你说一次 → 做一次 → 自己停」。
- **窗口不可见就停**：最小化、被挡住、没开，都会直接说明原因，不会硬刷。
- **管理员权限会被识别**：抖音以管理员身份启动时，普通权限的机器人发不进任何消息（Windows UIPI 拦截），
  面板和指令会明确提示「退出后正常打开一次」，不会假装成功。

### 移除
- `worker/douyin_worker.py`（Playwright 无头浏览器方案）以及它的子进程调度、超时、结果文件读取逻辑。

## 用之前请确认

1. 本机装好抖音 PC 客户端（默认 `D:\抖音\douyin\douyin.exe`，路径可在设置里改）。
2. **抖音用普通权限打开**。如果你之前是「以管理员身份运行」的，右键托盘退出、然后正常双击打开一次，
   否则机器人碰不到它——这是 Windows 的权限隔离，绕不过去。
3. 需要 `pywin32` 与 `Pillow`（`pip install pywin32 pillow`）。

## 能力边界（刻意做窄）

- 只会做三件事：打开客户端、截图、在抖音窗口内滑到下一个视频。
- 不点赞、不评论、不关注、不私信，也不搜索。
- 不会去点抖音窗口以外的任何地方；窗口被挡住或最小化就立刻停手。
- 所有改动只发生在抖音模块内，双主题、上下文置顶、记忆、小屋等其他功能一行未动。

## 已知限制

- 画面识别靠文字判断界面类型，画面里几乎没字时会显示「没认出来是什么界面」，此时不会继续翻页。
- 截图走的是屏幕上真实可见的画面，所以抖音窗口必须露出来（不能全屏压住它，也不能最小化）。
