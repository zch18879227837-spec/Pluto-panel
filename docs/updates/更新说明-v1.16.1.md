# PLUTO panel v1.16.1 更新说明

**发布日期**：2026-10-31
**版本号**：1.16.1
**类型**：Bug 修复（无新增功能、无界面变化、无数据结构变化）

---

## 一、这次修的是什么

**现象**：在面板里把主题切到浅色（或深色），刷新 AstrBot 界面之后，主题又回到默认那一档，
必须再手动点一次才恢复。

**根因**（不是主题没存住，是首屏没把存住的设置读回来）：

1. 面板启动时先按默认值渲染（默认深色），然后才请求 `/page/overview` 拿你的真实设置；
2. 这次请求只要失败一次——后台刚重启、插件还在加载、网络抖一下——原来的代码会把异常吞掉，
   只显示一条横幅，于是「应用设置」这一步被整个跳过；
3. 首屏那条「失败就重试」的分支从来没生效过，因为 `loadOverview()` 内部捕获了异常、永远不抛，
   外层永远以为成功；
4. 另外启动时还会先把 AstrBot 宿主主题套到面板上，用户自己选的主题会被短暂盖掉。

结果就是：主题值在 `settings.json` 里好好的，但刷新后界面用的是默认色，直到你手动点一次主题按钮。

## 二、改了什么

| 改动 | 说明 |
| --- | --- |
| 首屏重试 | `loadOverview()` 改为返回成功/失败；启动时最多重试 4 轮，间隔 0.7s / 1.4s / 2.1s |
| 主题取值顺序 | 固定为「服务端设置 → 本地偏好 → 宿主主题 → 深色」，宿主主题只做兜底 |
| 保存失败可见 | 主题保存失败会弹出「主题没存进后台：…」，不再静默 |
| 本地偏好兜底 | 支持 localStorage 时额外存一份，首屏先贴回去；插件 iframe 被 sandbox 时自动跳过 |

## 三、不受影响的部分

- 双主题（DeepSeek 蓝调 / 象牙白）的配色令牌、卡片、动效：一行没动；
- 上下文监控、置顶、小屋、抖音 PC 客户端、联网搜索、事件日志等其它模块：一行没动；
- `settings.json` 结构没变，已有配置直接沿用。

## 四、怎么验证

1. 面板切到浅色 → 刷新 AstrBot 界面（F5）→ 应当直接是浅色，不用再点；
2. 反过来切深色 → 刷新 → 应当保持深色；
3. 故意让后台忙一下（例如刚重载插件时立刻刷新）→ 面板会在 1～2 秒内自己恢复成你选的主题。

## 五、已知情况

- 如果 AstrBot 后台长时间连不上（超过约 5 秒），面板拿不到设置，会退回深色并显示错误横幅；
  后台恢复后刷新一次即可。
