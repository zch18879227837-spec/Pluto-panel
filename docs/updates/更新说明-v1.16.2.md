# PLUTO panel v1.16.2 更新说明

**发布日期**：2026-10-31
**版本号**：1.16.2
**类型**：小更新（只动日记本模块的提示词与文案）

---

## 一、为什么改

之前的日记本规则是「一句话讲清发生了什么、意味着什么」，模型照着写出来就是摘要：
干、短、像工作汇报，读起来没有人的味道。这一版把写法换成私人日记，
让它记当地当天真正发生的小事，以及那一刻的感受。

## 二、改成什么样

| 维度 | 以前 | 现在 |
| --- | --- | --- |
| 视角 | 第三人称概述 | 第一人称，口语、松弛 |
| 内容 | 提炼「发生了什么、意味着什么」 | 细碎日常：说了什么、吃了什么、光怎么挪、心里怎么动了一下 |
| 篇幅 | 一句话，默认很短 | 在单篇字数上限内尽量写满，至少写到一半 |
| 时间 | 一天随意几篇 | 上午 / 下午 / 晚上各一篇，各自贴合时段氛围 |
| 语气 | 结论式 | 允许啰嗦、跑题、自我吐槽；不提炼关键词、不总结 |

示例（同一件事，新写法）：下午本来是想好好看书的，光刚好落在书页上，字都有点发黄。
看了没几页眼睛就开始打架，后来干脆把书扣在胸口睡了……一睁眼屋里都暗了，
窗玻璃上只剩一点灰蓝色的天，愣了好一会儿才想起来是下午不是早上。

## 三、配置约束一个字没放宽

- 日记本总开关关闭 → 不写、不检索、不注入；
- 单日最多篇数 → 到量就跳过，提示里会直接写「今天还剩 0 篇额度」；
- 单篇字数上限 → 超长照旧截断（提示里会告诉它上限是多少）；
- 每次注入条数 → 只推相关性最高的几条；
- 权重、归档、检索排序、按人存储的目录结构 → 全部原样。

## 四、改动范围

- `main.py`：`DIARY_WRITE_RULE`（提示词）与 `_diary_context_block()`（注入文案，
  多了「此刻时段 + 今日额度」两行），新增两个只读小工具函数；
- `views/dashboard/index.html`：日记本页的提示与页脚两段说明；
- 其它模块（双主题、上下文置顶、小屋、抖音 PC、联网搜索、事件日志）：零改动。

## 五、怎么验证

1. 打开日记本总开关，把「单篇字数上限」调到 300 以上；
2. 随便聊一件今天发生的小事，一两轮后看「日记正文」卡片；
3. 应该能看到一篇第一人称、有场景和情绪的日记，而不是一句话摘要；
4. 同一天同一时段再聊，不会再写第二篇；把「单日最多篇数」调到 1 就会明确停止。
