# PLUTO panel v1.16.4 更新说明

> 发布日期：2026-11-01 ｜ 类型：日记本行为修正（不改数据结构、不影响其它模块）

## 1. 小屋里的自言自语不再进日记

之前 `iso-chat` 在小屋「自动漫游 / 走到点位后自己说一句」时也会写日记，于是同一天里出现两条 17:54 的记录：

- 「在『床边』说了句：床边的地毯软软的，我踩上去就不想动了……」
- 「大肥鱼回：床边的地毯软软的……」

这些只是场景台词，不是一天里真的发生过的事，它们把真正的日记挤掉了（单日 3 篇额度就没了）。

现在：

- **只有主人在小屋对话框里真的说话**，才记一条，并且把一问一答合成一笔（「在小屋里跟主人聊天：主人说『……』，我回『……』」），权重 low。
- 自动漫游、到点位自言自语，一律不写日记。

## 2. 日记按句收尾，不再截成半句

原来超过「单篇字数上限」时直接按字符硬切，常常停在一句话中间。现在 `_diary_fit()` 的收尾顺序是：

1. 没超限 → 原文；但结尾若是逗号/顿号/分号，补一个句号；
2. 超限 → 在额度内找最后一个句末标点（。！？…」”），要求至少用满 60% 额度；
3. 找不到 → 退到最近的逗号/顿号断开并补句号（至少 75%）；
4. 全文没有任何标点 → 才压缩并加省略号。

提示词同步改成「整篇必须在 <built-in function max> 字以内写完，宁可少写一件小事，也不要写到一半被截断，最后一个句号要落满」。

## 兼容性

- 日记存储结构（`diary_log/<umo>/<cid>.json`）、权重、检索注入、单日篇数上限全部不变。
- 旧日记原样保留；面板「日记本」页照常显示。
