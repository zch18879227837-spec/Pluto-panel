# PLUTO panel v1.17.0 · 更新说明

发布日期：2026-11-02
主题：**选择性上下文剪枝**（让记忆更完整，不再整轮静默丢弃）

## 为什么做这次改动

之前 AstrBot 核心每轮请求前都会按 `max_turns` 从最早处整轮丢弃历史（默认 30 轮），丢弃会落库、没有备份也没有日志。表现就是「越聊越记不住前面」，而且丢的是整轮，约定、承诺、数字这类关键原句一起没了。

这次把腾地方的工作交给插件自己做：**先摘原句、再折叠摘要、最近 N 轮不动**，并且整份备份可回滚。

## 你会看到什么

1. 核心配置 `agent_runner.config.compression.max_turns` 已改为 `-1`（不再按轮数丢）。
2. 「压缩承接」页多了一张 **选择性剪枝** 卡片：
   - 启用选择性剪枝（默认开）
   - 模型复核灰色片段（默认开，一次批量打分）
   - 触发轮数 26 / 触发 Token 55000 / 保留最近轮数 10 / 单次最多丢弃 40%
   - 立即剪枝、回滚上次剪枝
3. 剪出来的第一条是「记忆卡」，长这样：

```
【记忆卡 · 前 19 轮里必须原句记住的 14 句】
- [主人] 说好了明天早上七点叫我起床
- [肥鱼] 路上要下雨的话伞带上，今天中雨的
（这些是原话摘录，涉及方向的主语也照抄，别改。）
```

## 行为细节

- **三层打分**：规则（约定/提醒/时间点/数字/偏好禁忌/进行中/强情绪保原句，寒暄与系统提示丢弃）→ 长期记忆（和 livingmemory 高重要度事实重合加分）→ 模型（灰色片段 0–3 分）。
- **防误伤**：单次丢弃超过 40% 的，多出来的部分改走摘要，不再凭空消失。
- **没收益就不动**：短会话里卡片+摘要可能比原文更长，省不到 12% 会直接跳过，并且退避重试。
- **可回滚**：每次落库前备份到 `carry_backups/<会话>/<cid8>-<时间>.json`，「回滚上次剪枝」按最新备份还原。
- **摘要清洗**：自动去掉「配置项：未提及」、本机路径、情绪标记这类噪声，压到 700 字内。

## 兼容性

- 双主题、置顶、小屋、抖音、日记、联网搜索等模块的行为与存储不变。
- 只新增 `prune` 段配置与 4 个面板接口；老配置文件会自动补默认值。
