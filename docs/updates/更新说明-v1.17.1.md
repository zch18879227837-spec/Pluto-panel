# PLUTO panel v1.17.1 · 更新说明

发布日期：2026-11-02
主题：**主动消息不再只会「接着上一句」**

## 之前是什么样

主动消息的素材只有抖音摘要与联网搜索，提示词又写死「最后一句是我说的，要接着这个话头说」。结果就是你一安静，它就复述你上一句问过的话（比如「你说豆包正经形象长啥样」），看着像只会接话的复读机。

## 现在改了什么

素材扩成三类：

1. **旧话题**：从当前会话往前 12–40 轮里抽一条你说过的、有内容的话（自动跳过「[图片]」「嗯」「在吗」这类占位与短句）。
2. **日记**：最近两篇日记里的一个片段（去掉「大肥鱼回：」前缀，每条截 60 字）。
3. **小屋**：她此刻在小屋的哪个位置、最近一个动作（小屋功能关着时自动跳过）。

起头方式三选一，随机指派：

- A 接着刚才的话头
- B 想起更早的旧事或日记里的片段
- C 说说自己这会儿在干什么

另外放宽了审稿：现在允许主动提起旧事和自己此刻的状态，只驳回编造事实、把旧事说成刚发生、空话套话、替主人编造。

## 人设同步

人设里补了一句「开头别总接着上一句」，写清三种起头怎么挑；顺手把「主人不在时我会自己刷会儿抖音」改成「自己待着，翻翻旧事」，因为 v1.16.0 起已经没有自动刷视频了。

## 兼容性

- 只改 `proactive.py` 的素材与提示词，调度、静默期、去重、风控、存储结构都没动。
- 三类素材任一为空自动跳过，不会因此发不出消息。
