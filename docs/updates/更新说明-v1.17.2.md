# PLUTO panel v1.17.2 · 更新说明

发布日期：2026-11-02
主题：修「剪枝之后面板变成 0 Token / 空会话」

## 你看到的现象

会话明明有 60 条历史，面板却写着 `0 / 1,000,000 Token`，还挂了个「空会话」标签。

## 为什么

1. **写回归零**：压缩、选择性剪枝、回滚这三条路径在写回历史时，顺手把 `token_usage` 写成了 0。面板显示的正是这个字段，于是变成 0。
2. **只能等下一轮**：`token_usage` 的真实值来自上一次请求服务端返回的 usage，要等你再发一条消息才会被覆盖，所以在两条消息之间它会一直显示 0。
3. **标签误判**：前端只按 `used === 0` 判断「空会话」，有历史的会话也被挂上了这个标签。

## 改了什么

- 三条写回路径改为写入**新历史的估算值**（和面板估算同一套公式：中文 ×0.6 + 其它 ×0.3 + 每条 4）。
- 「空会话」改成 `用量为 0 且没有内容` 才算；有内容但数值还没刷新的，显示中性的「用量待刷新」，鼠标悬停有解释。
- 你这条已经归零的会话按估算补回了 3448，历史内容一条没动。
- 清空会话仍然写 0——那是真的清空了。

## 注意

估算只在两次请求之间顶替，下一轮对话后会自动换成服务端真实用量。所以看到 3,448 这种「不太整」的数字，是估算，不是新花的钱。
