# PLUTO panel v1.17.3 · 更新说明

发布日期：2026-11-02
主题：**摘要不再设字数上限**，该记多少写多少

## 改了什么

- 摘要提示词里删掉了「不超过 N 字」。现在是：「长度按内容需要来——该记的都写进去，别为了省字数丢掉约定、数字和原话；也不要注水把一句话拆成三句。」
- 增强摘要模式（提取数字/配置/代码要点）也不再有总字数限制。
- 选择性剪枝那条路的摘要在落库前仍会清洗噪声（「配置项：未提及」、本机路径、情绪标记），但**不再按 700 字截断**。
- 面板「压缩承接」页的「摘要字数上限」输入框已移除；配置文件里残留的 `summary_max_chars` 仍然能读，但不再影响摘要。

## 这样做的代价

摘要可能变长（实测同样一段历史，旧模板 300 字左右，新模板会写到 400–700 字，取决于内容）。多出来的部分每轮都会跟着上下文走，估算每 100 字约 60 字中文 + 40 字符 ≈ 48–70 token。

换来的是：约定、数字、原话不会被字数挤掉——这也正是之前「记岔方向」的土壤。

## 兼容性

- 其它模块（小屋、抖音、日记、搜索、事件日志）行为不变。
- 老配置无需迁移。
