# PLUTO panel v1.18.1 · 更新说明

发布日期：2026-11-02
主题：抖音网页版从「能跑起来」到「真的能登录、能刷、能拉私信」

## 这次修了什么

1. **扫码登录点不动**：以前在无头模式里跑，窗口根本看不见；请求还会卡住 180 秒。现在会强制拉起有头窗口，用真实鼠标点「登录」，把二维码弹出来，扫完自动存 cookie。
2. **登录框被页面刷新顶掉**：未登录时不再跳私信页。
3. **重载后浏览器起不来**：启动前先清理被旧进程占住的 profile 锁。
4. **登录态误判**：重载后页面停在 `about:blank` 会被判成「未登录」；现在先回首页再判断，播放中直接视为已登录。
5. **滑块验证码**：检测到就把窗口亮出来，提示你去窗口里手动拖一下。

## 怎么用

1. 面板「抖音浏览」页打开「抖音网页版」开关（默认已开），`headless` 默认关闭。
2. 点「扫码登录」→ 在弹出的浏览器窗口里扫码 → 面板状态会自动变成「已登录」。
3. 管理员在 QQ 里说 `/douyin_start` 开始刷、`/douyin_stop` 停；`/douyin_next`、`/douyin_like`、`/douyin_comment 文本`、`/douyin_share` 同理。
4. 所有动作都先过公共风控（同一套 `risk_core`），被限流时会告诉你等待时间。

## 已知限制

- 「精选」弹窗播放器是沉浸式的，页面里查不到赞/评/分享按钮，这三项目前是选择器 + 快捷键兜底，还没在真实页面校准。
- 私信需要一个真实会话来验证；当前账号消息列表是空的。
