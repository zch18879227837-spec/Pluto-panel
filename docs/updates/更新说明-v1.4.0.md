# PLUTO panel v1.4.0 更新说明

> 版本：1.3.3 → 1.4.0 ｜ 作者：Charon ｜ 插件标识：`astrbot_plugin_token_panel`（不变）

## 一、本次新增

### 1. 「联网搜索」标签

| 模块 | 内容 |
| --- | --- |
| 概况 | 今日搜索次数、总次数、成功 / 失败计数与成功率、平均耗时 |
| 记录 | 时间、关键词、结果条数、耗时、成败；关键词过滤并高亮命中片段 |
| 清空 | 二次确认后只清本地日志表，不动 websearch 插件配置 |

数据来自 websearch 插件的 `search_log.db`，面板用只读连接读取，读失败就显示空列表，不抛异常。

### 2. 「抖音游客浏览」标签

| 模块 | 内容 |
| --- | --- |
| 状态 | 自动浏览开关、今日累计（次数 / 视频数 / 分钟）、上次浏览时间、风控计数 |
| 策略 | 浏览间隔、单次时长、单次视频数、每日次数上限、免打扰起止、关键词过滤、结束通知 |
| 记录 | 每次浏览的时间、模式、视频数、时长与看过的标题（最多 3 条预览） |
| 操作 | 「立即浏览一次」异步触发，不阻塞页面 |

抖音浏览的真实浏览器动作放在 `worker/douyin_worker.py`，由插件用子进程拉起：

- 只访问抖音精选页，未登录、不点赞、不评论、不搜索；
- 每个视频按「时长与 20 秒取小」模拟停留，滚动间隔 1.4–3.2 秒随机；
- 遇到图形验证码立即停止并记 `risk=true`，同时通知管理员；
- 单次时长 / 条数 / 每日次数 / 免打扰时段四重限制，先到先停。

### 3. 新增 7 条指令

| 指令 | 权限 | 说明 |
| --- | --- | --- |
| `/net_log` | 所有人 | 最近 5 条联网搜索记录 |
| `/dy_status` | 所有人 | 抖音浏览状态与今日累计 |
| `/dy_on` / `/dy_off` | 管理员 | 开关自动浏览 |
| `/dy_test` | 管理员 | 立刻浏览一次 |
| `/dy_log` | 管理员 | 最近 3 次浏览记录 |
| `/dy_set <参数> <值>` | 管理员 | 改浏览参数 |

## 二、没有改动的部分

- Token 估算公式：中文 ×0.6、其它 ×0.3、每条 +4，单条分别取整后求和。
- 压缩 / 承接的完整流程、异常分支、摘要模板、备份上限 20 份、日志上限 200 条。
- 存储路径：`settings.json`、`session_meta.json`、`compress_log.json`、`carry_backups/`。
- 原有 11 条指令（`/token_*` 5 条 + `/ctx*` 6 条）的名字、权限、行为。
- 5 个旧标签页的版式与交互；两套主题、象牙白 / 吸黑画布。

## 三、升级方式

1. 覆盖插件目录（或从插件市场更新），保留 `data/plugin_data/astrbot_plugin_token_panel/` 不动；
2. 后台「插件」页重载插件，或重启 AstrBot；
3. 打开「扩展功能 → PLUTO panel」，新标签页即可看到。

首次读取时，`settings.json` 会自动补上 `douyin` 段默认值（自动浏览默认关闭）。

## 四、依赖说明

- 联网搜索监控：依赖 websearch 插件存在并写过日志；没有时面板显示「还没检测到搜索日志」。
- 抖音游客浏览：需要 Playwright 与 Chromium：

```bat
python -m pip install playwright -i https://pypi.tuna.tsinghua.edu.cn/simple
set PLAYWRIGHT_BROWSERS_PATH=<playwright-browsers>
python -m playwright install chromium
```

没装时点击「立即浏览」会提示启动失败，不影响其它功能与机器人聊天。
