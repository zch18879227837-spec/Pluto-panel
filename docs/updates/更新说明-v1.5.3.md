# 更新说明 v1.5.3

**一句话：设置抽屉拆成左侧一级菜单。** 面板左侧导航现在直接列出「行为 / 显示 / 主动消息 / 压缩承接 / 阈值与播报」五个入口，点击即在右侧主区展开对应配置，不再需要先点齿轮、再在抽屉里往下翻。

## 一、左侧导航

| 位置 | 菜单项 | 说明 |
| --- | --- | --- |
| 1 | 上下文监控 | 原数据页，默认选中 |
| 2 | 搜索监控 | 原搜索监控 |
| 3 | 抖音浏览 | 原抖音浏览 |
| 4 | 抖音风控调速 | 原风控调速 |
| — | 分隔线 | 上半段是「看」，下半段是「调」 |
| 5 | 行为 | 原抽屉·行为（自动进度播报、调试日志、上下文上限） |
| 6 | 显示 | 原抽屉·显示（主题、配色、缩放） |
| 7 | 主动消息 | 原抽屉·主动消息（开关、参数、会话、发送日志） |
| 8 | 压缩承接 | 原抽屉·压缩承接 |
| 9 | 阈值与播报 | 原抽屉·阈值与播报（预警阈值、高危阈值、播报冷却） |

- 齿轮按钮与整个抽屉（含遮罩、滑入动画、Esc 关闭）已移除，主区成为唯一内容区。
- 图标沿用统一的线性风格（24×24、1.7 描边），新增五项为：行为=开关、显示=显示器、主动消息=对话气泡、压缩承接=收纳盒、阈值与播报=铃铛。
- 选中项仍是原来的高亮（浅色底 + 加粗 + 图标转强调色），切换时右侧内容沿用原有的淡入过渡（`.panel-view.active` 的 rise 动画）。
- 窄屏（≤900px）下侧栏折成顶部横向导航带，分隔线自动隐藏，可横向滑动。

## 二、主动消息

原来这段是抽屉里唯一自带 DOM 的区块，抽屉撤掉后单独成页：

- 三张卡片：主动消息（说明 + 参数）、会话、发送日志（右上角「清空」）。
- 表单控件、文案、接口调用（`proactive-overview` / 保存 / 清空）原样复用，未改任何字段。
- 数据改为进入该页时才拉取（`__ppLoadProactive`），与其余页面的懒加载一致。

## 三、未改动的部分

- 所有 API 接口、参数名、默认值、校验范围、保存逻辑。
- 卡片、进度条、滑块、表格、字号与排版。
- 主题系统（claude / deepseek × ivory / ink）、缩放（80–140%）、刷新按钮、横幅提示、页脚。
- 抖音、搜索、承接等页面的数据计算与轮询行为。

## 四、顺手修掉的两处

1. 旧代码里点齿轮会进入 `bindTabs`，`data-view` 为空时匹配到 `view-undefined`，把当前页面一起清空；现在齿轮已删，且保留 `if (!tab.dataset.view) return;` 兜底。
2. `#view-general` 原本带 `active` 类，与默认选中的上下文监控冲突（靠脚本兜），现在标记已去掉，首屏不再有瞬时闪烁。

## 五、怎么用

刷新页面即可（面板每次请求都从磁盘读 HTML，带 `no-store`，不用重启 AstrBot）。插件版本号同步为 1.5.3。
