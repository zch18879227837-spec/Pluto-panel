# 更新说明 v1.5.4

**一句话：按钮有了统一的线性图标，交互有了克制的微动效。** 布局、配色、字号、卡片位置、参数与数据计算全部原样，只加了一层「图标 + 过渡」的皮。

## 一、图标

- 新增 12 个 24×24 线性图标（refresh / stats / compress / summary / trash / limit / filter / play / arrow / archive / close / check），统一 2.0 描边、圆头圆角、`currentColor` 取色，深色主题自动适配。
- 覆盖范围：所有原生按钮、模态框按钮、会话行操作（压缩上下文 / 生成承接摘要 / 清空 / 查看统计 / 设置上限）、搜索页（过滤 / 清空）、抖音页（立即浏览 / 刷新）、主动消息页（清空）。
- 图标插在文字**前面**，`gap: 6px` 与文字居中对齐；实测按钮宽高与插入前逐像素一致（`before/after` 高度对比 `[32,30,30,30]` 完全相同），不挤占文字、不改变排版。
- 选中 / 悬浮时图标透明度从 `0.85 → 1`，强调色跟随文字变（`transition: opacity/color .18s`）。
- 生成方式：`paintIcons()` 给缺图标的按钮补一个（键位优先级 `data-act` → `id` → 文案前缀），`watchIcons()` 用 `MutationObserver` 给动态插入的按钮补，因此会话列表、模态框里后渲染的按钮也同样带图标。
- 两处刻意不加：主题色板按钮（`theme-ivory` / `theme-ink`，本身就是颜色预览）。

## 二、动效

| 交互 | 效果 | 参数 |
| --- | --- | --- |
| 悬浮按钮 / 导航 / 色板 | 上移 1px + 放大 1.015，背景与边框淡入 | 180ms `cubic-bezier(.2,.8,.3,1)` |
| 按下 | 回弹到 0.972 | 90ms |
| 悬浮卡片 / 会话行 / 统计块 | 上移 1px，边框转强调色 26% | 180ms |
| 刷新 / 立即浏览 | 图标自转，按钮进入 `is-busy` 态 | 0.9s/圈，完成后留 260ms |
| 切标签 | 右侧内容淡入（沿用原有 rise 动画） | 220ms |
| 会话 Token 进度条 | 插入后由 0 补间到真实宽度 | 550ms `cubic-bezier(.22,.61,.36,1)` |
| 统计数字 / 风控进度 | 数字补间而非跳变（easeOutCubic） | 460ms |
| 预警 / 高危标识 | 柔和呼吸微光 | 3.8s 循环，box-shadow 0→3px |
| 对应进度条 | 微弱光晕呼吸 | 3.8s 循环，drop-shadow 0→2.5px |

- 全部使用 `transform` / `opacity` / `box-shadow`，不触发重排；卡片只位移不缩放，避免整块内容抖动。
- `prefers-reduced-motion: reduce` 下所有过渡、动画、位移一律归零（实测 `animationName = none`、`transitionDuration = 0s`）。

## 三、未改动的部分

- 配色、色块、主题系统、缩放（80–140%）、字号与排版、卡片尺寸与间距。
- 所有按钮的文案、位置、点击行为；所有接口、参数名、默认值、校验范围。
- 数据计算、轮询周期、静默逻辑、风控参数。

## 四、怎么用

刷新页面即可（面板每次从磁盘读 HTML，带 `no-store`）。插件版本号同步为 1.5.4。

## 五、验证

- 1440×900：23 个按钮中 21 个带图标（另 2 个是主题色板）；九个页面逐个切换，图标覆盖率 100%，`consoleErrors` 为空。
- 几何量测：图标 14px、图标与文字间距 6px、图标与文字中心线齐平；对比插入图标前后 8 个按钮高度完全一致，无版式位移。
- 动效取值实测：`pill-breathe / 3.8s`、`bar-breathe`、`ico-spin / 0.9s`、进度条 `width 0.55s`。
- 减动效模式（`prefers-reduced-motion: reduce`）：`pill: none`、`spin: none`、`transitionDuration: 0s`。
- 390×844：侧栏横带 50px，`scrollWidth 390 = clientWidth 390`，无横向溢出。
