AstrBot · Extension Panel

PLUTO panel（普鲁托面板）

读取 AstrBot 官方会话统计，查看每个会话的上下文占用、预警状态与清空操作。数据仅在打开面板时拉取，不做轮询。

行为

控制机器人何时提醒你上下文快满了。

自动进度播报 用量越过预警线时提醒一次，同一会话 30 分钟内不重复
调试日志 写入插件日志，方便定位读取失败的原因

数据来源

面板里的每个数字都来自 AstrBot 自身，不做估算。

  • 已用 Token会话记录中最近一次 LLM 请求返回的 token 总数（官方 token_usage 字段）
  • 窗口上限Provider 配置的 max_context_tokens，未配置时按 models.dev 元数据解析
  • 占用百分比已用 ÷ 窗口上限；模型没有上限时显示「无法计算占比」

QQ 指令速查

全部带 token_ 前缀，不占用 AstrBot 原生 /ctx 等指令。

  • /token_ctx查看当前会话的用量进度条（所有人可用）
  • /token_ctxon开启自动进度播报（管理员）
  • /token_ctxoff关闭自动进度播报（管理员）
  • /token_clearctx清空当前会话上下文，需二次确认（管理员）
  • /token_ctxset 80修改预警百分比阈值（管理员）

手动压缩与承接

也可以直接在会话里发指令；压缩会保留会话 ID，承接会新建会话并切过去。

  • /ctx查看当前会话用量与占比（所有人可用）
  • /ctx_compress 8把较早对话压成摘要，保留最近 8 轮（管理员）
  • /ctx_continue 4生成承接摘要并切到新会话，保留最近 4 轮（管理员）
  • /ctx_sessions列出近期会话及承接关系（所有人可用）
  • /ctx_switch 前缀按会话 ID 前 8 位切回旧会话（管理员）
  • /ctx_auto on 80开关请求内自动压缩并查看当前配置（管理员）
